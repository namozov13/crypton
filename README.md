# 🧪 Crypton — Kimyoviy Elementlar Davriy Jadvali

**Crypton** — kimyoviy elementlar haqida batafsil ma'lumot beruvchi, zamonaviy, dinamik va qulay interaktiv davriy jadval platformasi. 

Ushbu loyiha kimyo fanini o'rganayotgan o'quvchilar, talabalar va fanga qiziquvchilar uchun elementlar xususiyatlarini tez va oson topishga yordam beradi.

## ✨ Asosiy Imkoniyatlar (Features)

* 🔍 **Tezkor Qidiruv:** Elementlarni nomi, belgisi (simvoli) yoki tartib raqami bo'yicha onlayn qidirish.
* 🌙 **Dark Mode (Qorong'i rejim):** Zamonaviy va ko'zga qulay bo'lgan qorong'i va yorug' rejim interfeysi.
* 📊 **Batafsil Ma'lumotlar:** Har bir elementning kashf etilish tarixi, tabiatda tarqalishi va ishlatilish sohasi.
* 📱 **Moslashuvchan Dizayn (Responsive):** Barcha turdagi qurilmalarda (telefon, planshet, kompyuter) qulay ishlash.

---

## 🛠 Ishlatilgan Texnologiyalar (Tech Stack)

* **HTML5** — Sahifaning tuzilishi va semantik strukturasi.
* **CSS3** — Stillar, responsive dizayn va animatsiyalar.
* **JavaScript (ES6+)** — Dinamik interaktivlik va ma'lumotlar bilan ishlash mantiqi.
* **JSON Database** — Elementlar haqidagi ma'lumotlar bazasi (`data.json`).
* **Git & GitHub Pages** — Versiyalarni boshqarish va bepul hosting.
